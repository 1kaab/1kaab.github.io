What it is

Physics-based audio
motion synthesis

Sonolumos is a real-time signal processing toolkit that maps audio features— spectral centroid, RMS energy, onset flux—through a layered physical model to produce continuous motion parameters.

The pipeline is modular: Geometry shapes the raw feature signal, Medium introduces inertia and damping, and Hysteresis adds memory and threshold behaviour. Each stage can be tuned independently or bypassed.

Output goes wherever you need it—OSC, MIDI, CSV, or directly into a connected host via the 44 plugin bridge.

Streaming pipeline

Process microphone or line input in real time, frame by frame, with sub-50 ms latency at typical chunk sizes.

Geometry · Medium · Hysteresis

Three independent physics stages per parameter route. Inertia, viscosity, memory, and gating—all continuously adjustable during a live session.

Brown pan walk

An Ornstein–Uhlenbeck 2-D random walk driven by audio energy, producing organic, non-repeating spatial trajectories.

Running normaliser

Per-feature adaptive normalisation keeps the pipeline calibrated to the current sound source without manual gain staging.

OSC & MIDI output

Route any parameter to any address. Works with Resolume, TouchDesigner, Reaper, Max/MSP, and any OSC-capable host.

Batch mode

Process audio files offline for previewing motion trajectories, exporting CSV datasets, or training motion models.

Evolutionary optimisation

DEAP-powered parameter search finds GMH configurations that best reproduce a target motion profile—automated tuning across the full geometry, medium, and hysteresis parameter space.
