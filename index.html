engine

sound becomes motion

A motion engine. Sound signals become motion signals. Using spectral analysis, a parameter space consists of three phases — each one a separate space, all operating within a single unified field. This is where sonolumos does its work.

Geometry

Fingerprint

The fingerprint of the signal — invariant when using the same spectral feature. Signals map onto color 3D space models inspired by bioluminescent spectral ranges.

Medium

Oscillation

Oscillations in relation to the signal. The mode of transfer — from signal into synthesizer into plate.

Hysteresis

Memory

The memory of the signal transfer function. Threshold behaviour, saturation, and entropy.

ice, water, vapor — Geometry is a frozen state. Medium changes it, and is the mode of transfer. Hysteresis is much higher in entropy. The engine evolves with these phase relations as separate spaces, unified.

analysis tool

evolutionary training

Set objectives. Run trainings. Visualize and compare. An evolutionary search over the GMH parameter space, guided by objectives chosen for the signal at hand — starting from the species.

synthesizer

karamuto model

An LFO that latches to the input using the karamuto model. The synthesis voice layer, in series with the physical plate.

physical installation

light, plate
& lens-focus

FLP — three modalities, one physical output.

Light

Color space 3D models mapped to bioluminescent spectral ranges. The light source is the sound.

Plate

A resonant layer of the synth. Substrate moving is motion — it is both a display and a feedback phenomenon for the project.

Lens-focus

Focus adjusting driven by the hysteresis signal.
